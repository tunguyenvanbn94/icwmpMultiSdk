# icwmp — thay đổi so với upstream fork `nvta2/icwmp` master `51513f5` (2022-03-14)

Bản gốc: icwmp (iopsys, dòng 3.x) cho OpenWrt — config UCI, backend data model
`libbbfdm`/`libtr098`, hành động hệ thống (reboot, download, apply) qua script
`/usr/sbin/icwmp` (pipe JSON). Bản này thêm glue platform (`inc/icwmp_platform.h`) để
cùng source chạy trên nhiều SDK. Từ 22/09/2026 có **ba** platform
(`./configure --with-platform=`, `--enable-bdk` là alias của `bdk`):

| Platform | Glue | Config of record của ACS |
|---|---|---|
| `uci` (mặc định) | `uci/icwmp_uci.c` (rỗng) | UCI `cwmp` |
| `bdk` | `bdk/` — attach Distributed MDM, hành động bằng C | MDM `Device.ManagementServer.*` |
| `mtk` | `mtk/` — mirror UCI `easycwmp` ↔ `cwmp`, hành động qua `scripts/mtk/icwmp.sh` | UCI `easycwmp` (WebUI, DHCP option 43, stuncd) |
