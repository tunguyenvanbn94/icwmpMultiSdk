# libtr098 — thay đổi so với upstream iopsys `bbf/tr-098` master `dca7ba5` (2020-05-31)

Bản gốc là data model TR-098 của iopsys cho OpenWrt: mọi object đọc/ghi UCI + ubus của
OpenWrt. Bản này thêm một **platform seam** để cùng engine chạy trên nhiều SDK, giữ
nguyên đường OpenWrt gốc. Từ 23/09/2026 mỗi SDK là **một thư mục tự chứa** dưới `sdk/`
(`./configure --with-sdk=`, tên cũ `--with-platform` vẫn nhận):

| SDK | Storage data model | Source | Xoá được |
|---|---|---|---|
| `uci` (mặc định) | UCI OpenWrt, module portable | `sdk/uci/`, `tr098/*.c` | `./tools/sdk-prune.sh <giữ lại>` |
| `bdk` | Broadcom Distributed MDM (TR-181) qua `libbcm_generic_hal` | `sdk/bdk/`, `sdk/bdk/dm098/` | nt |
| `mtk` | UCI + ubus của sản phẩm HNI, data model **C** | `sdk/mtk/`, `sdk/mtk/dm098/`, `sdk/mtk/compat/` (tạm) | nt |

Cây gốc của data model không viết ở đâu cả: mỗi module trong `tr098/` hoặc `sdk/<n>/dm098/`
tự đăng ký với `dm_registry.h` và registry gộp theo tên object.

## Giữ nguyên (engine + helper)

`dmtr098.c`, `dmentry.c` (trừ hook), `dmmem.c`, `dmubus.c`, `dmjson.c`, `dmuci.c`,
`dmcommon.c` (trừ path), `md5.c`, `wepkey.c`, `tr098/managementserver.c`,
`tr098/softwaremodules.c`.
